# خطة التنفيذ

## النطاق
إعادة بناء تجربة Deep Kitchen 3D داخل React + Babylon.js، مع مشهد مطبخ عميق، شخصية نورة الإجرائية، ومسارات واجهة عربية مستوحاة من الملفات المرفقة.

## شرائح المخاطر
1. **المشهد الإجرائي:** غرفة بطبقات واضحة، إضاءة warm/cool، وضباب خفيف دون تحميل نماذج خارجية.
2. **الشخصية:** silhouette مقروء من أجزاء هندسية مع idle animation مرئية.
3. **التغليف:** واجهة RTL فوق canvas مع responsive mobile rail.
4. **المسارات:** المسارات الأساسية من الملفات المرفقة تعيد استخدام shell واحد مع حالة محطة مختلفة.

## معايير التحقق
- ظهور عمق foreground / midground / background في لقطة سطح المكتب.
- ظهور نورة كشخصية كاملة داخل المشهد مع حركة تنفس خفيفة.
- عمل أزرار المحطات والتنقل بين الوضعيات.
- عدم وجود أخطاء TypeScript أو أخطاء console حرجة.
- قابلية القراءة على عرض هاتف.
