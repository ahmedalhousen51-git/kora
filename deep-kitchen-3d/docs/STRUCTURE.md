# بنية المشروع

- `client/src/App.tsx`: shell RTL، التنقل، لوحات المحطات، ومحتوى الحالة.
- `client/src/components/GameCanvas.tsx`: دورة حياة Babylon، الكاميرا، الإضاءة، هندسة المطبخ، وشخصية نورة.
- `client/src/index.css`: نظام ألوان Neo-Folk Editorial، التخطيط، الاستجابة والحركة.
- `client/index.html`: metadata العربية.

## طبقات العرض
React هو الإطار والمعلومات التفاعلية، Babylon هو المسرح ثلاثي الأبعاد، والأصول المولدة تُستخدم في هوية الصفحة وصورة الشخصية.
