# ذاكرة المشروع

تم اختيار اتجاه «مطبخ الحكاية» مع واجهة عربية RTL. المشهد الإجرائي يعمل من دون نماذج خارجية، ويستخدم Babylon.js مع camera orbit وضوء كهرماني وضوء حواف زمردي وظلال ناعمة. الشخصية الجديدة اسمها نورة، وتتحرك بذبذبة idle بسيطة قابلة للرؤية.

الملفات المرفقة استُخدمت كمصدر للمفردات والمسارات العامة، بينما استُبدلت الصفحات المنفصلة بواجهة React موحدة حتى تبقى التجربة متماسكة على سطح المكتب والهاتف.
