# حزمة إضافة Deep Kitchen 3D

هذه الحزمة تحتوي على الأكواد الجاهزة لإضافة تجربة المطبخ ثلاثية الأبعاد إلى مشروع React + Vite. لا تحتاج إلى تعديل الأكواد يدويًا إذا كنت ستستخدم مشروع **Deep Kitchen 3D** الذي تم تسليمه لك؛ افتح المشروع واضغط **Publish** فقط.

## إذا كنت تريد تركيب الأكواد في مشروع React آخر

فك الضغط عن الملف، ثم انسخ الملفات بنفس المسارات التالية:

| الملف داخل الحزمة | المكان المطلوب داخل مشروعك |
|---|---|
| `client/src/App.tsx` | استبدل ملف `App.tsx` الحالي |
| `client/src/index.css` | استبدل ملف `index.css` الحالي |
| `client/src/components/GameCanvas.tsx` | أنشئ مجلد `components` إذا لم يكن موجودًا، ثم ضع الملف بداخله |
| `client/index.html` | استبدل ملف `index.html` الحالي |
| `package.json` | استخدمه كمرجع، ولا تستبدله إذا كان مشروعك يحتوي على حزم خاصة |

بعد نسخ الملفات، يجب تثبيت محرك Babylon.js مرة واحدة. إذا كان لديك شخص يساعدك أو تستخدم محررًا سحابيًا، اطلب منه تنفيذ الأمر التالي داخل مجلد المشروع:

```bash
pnpm add @babylonjs/core
```

بعدها شغّل المشروع بالأمر التالي:

```bash
pnpm dev
```

ثم افتح الرابط الذي يظهر لك في الشاشة. في مشروع WebDev، لا تحتاج إلى تنفيذ هذه الأوامر يدويًا؛ الملفات موجودة بالفعل داخل المشروع الجاهز.

## ما الذي تمت إضافته؟

المشهد ليس صورة ثابتة. تم بناء مطبخ ثلاثي الأبعاد قابل للدوران بالماوس، وفيه جدار بلاط، رفوف، أوعية، آلة إسبريسو، طاولة خدمة، إضاءة كهرمانية، إضاءة زمردية، وشخصية باريستا جديدة باسم **نورة**. الشخصية مصنوعة داخل Babylon.js من أجزاء هندسية واضحة، وتتحرك بحركة تنفس خفيفة أثناء الوقوف.

الواجهة عربية من اليمين إلى اليسار، وتحتوي على مسارات «المطبخ»، «المحاكاة»، «الباريستا»، و«الضيف». يمكنك تغيير المحطة من اللوحة اليمنى، وتشغيل وردية الصباح من الزر الأخضر، وتدوير المشهد بالسحب.

## أسهل طريقة لك كمستخدم غير مبرمج

لا تفتح الملفات ولا تغيّر الأكواد. استخدم نسخة المشروع الجاهزة المرفقة مع التسليم، وافتح لوحة المعاينة للتجربة. إذا أردت نشر الموقع، اضغط زر **Publish** في أعلى لوحة المشروع. وإذا أردت تعديل الاسم أو النصوص أو الألوان، أرسل لي التعديل باللغة العربية مثل: «غيّر اسم نورة إلى سارة» أو «أضف محطة الحلويات»، وسأعدّل الملفات لك.

> إذا ظهرت شاشة فارغة بعد تركيب الملفات في مشروع خارجي، فالسبب غالبًا أن Babylon.js لم يتم تثبيته أو أن المشروع يستخدم مسارات مختلفة. في هذه الحالة استخدم نسخة المشروع الجاهزة بدل التركيب اليدوي.

## الملفات الموجودة

الحزمة تشمل `App.tsx` للواجهة والتنقل، و`GameCanvas.tsx` للمشهد والشخصية ثلاثية الأبعاد، و`index.css` للتصميم والحركة، و`index.html` للعنوان واللغة العربية، و`package.json` لمعرفة الحزم المطلوبة.

## اقتراحات يمكن إضافتها لاحقًا

يمكن تطوير التجربة بإضافة سحب الأدوات وتحضير وصفة خطوة بخطوة، وربط شريط التقدم بدرجة الحرارة ووقت الاستخلاص، وإضافة أصوات ماكينة القهوة والاحتكاك بالأدوات.
